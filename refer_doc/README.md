# RFQ 项目正式文档（唯一源）

本目录是 MatrixNEXT RFQ 智能体项目的**唯一正式文档目录**。上级目录 `F:\Codex\MatrixNEXT` 下的同名 `RFQ_*.md` 已删除，避免出现多份副本后各自修订、互相矛盾。

## 文档地图

| 文件 | 作用 | 读到它的时机 |

| [RFQ赛题解析.md](./RFQ赛题解析.md) | **事实基线**。赛事素材的可核对事实，不含方案主张 | 任何需要确认“素材到底有什么”的时候 |

冲突时的优先级：**赛题解析（素材事实） > 行业无关基准（核心契约） > 开发计划 > 方案设计 > 需求清单**。赛题解析只写可核对的事实；方案里的定价参数一律是方案假设，不得当作赛事规则引用。V2 需求文档是"基准的工程化提案"，不是赛题要求，其优先级低于赛题解析（见 [RFQ_V2_REVIEW.md](./RFQ_V2_REVIEW.md)）。

## 维护规则

1. 只改本目录内的文件；不要再在上级目录或聊天目录里存副本。
2. 发现素材事实与文档不符时，先改赛题解析、再改方案与计划，并在开发计划 §1 的审核表中留一行记录。
3. 任何新增的 TBD 必须写明“这是方案假设”，且不得进入验收口径。
