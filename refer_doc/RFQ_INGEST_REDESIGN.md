# Ingest 改造与业务理解决策记录

日期：2026-11-03。状态：讨论形成的实施依据，尚未据此完成代码改造。实现可能并行演进，开工前应核对 ingest、perception、sources 和现有测试，复用已有能力。

## 目标与范围

让 Agent 理解不同客户邮件的内容、清单位置、列含义及业务要求，并输出统一 RFQ。六份赛事素材用于回归验证，不能成为固定格式假设。当前解析已有按载体处理的能力，问题应定位为固定表头、位置、PDF 行格式等假设，而非未经检查就声称按六个文件名匹配。

用户明确要求保持简单：现阶段业务尚在理解中，知识应帮助识别需求；只有缺失或冲突实际影响报价时才要求确认。不得把每个术语、类别或未知细节变成审批步骤。

## 第一阶段流程

1. 工具解码邮件，读取正文和附件，保留来源位置。Excel 使用结构化读取，PDF 提取文本，扫描件按实际需要补充 OCR。
2. Agent 理解邮件意图、定位清单、识别表头和列映射，抽取行项目、整单要求与行级要求，参考术语词典解释业务含义。
3. 代码校验结构、数量、单位和证据；可恢复的缺漏进行有界补读，仍缺失的字段明确标注。
4. 输出现有 RFQ / Line 契约，交给报价模块。字段扩展优先兼容现有调用方。

推荐先实现一次结构化理解加必要补读，无需多 Agent 或开放式无限循环。附件复用现有读取工具，但不假设第一个 sheet、第一行表头或固定列顺序。正则用于局部格式检查及辅助识别。

## 理解结果必须表达什么

- 客户希望完成的事项，哪些正文或附件是真正的询价依据。
- 每行的身份、料号、描述、数量、单位、件状、优先级、截止日期及附加要求。
- Part Number、MPN、手册件号分别保存，不能相互覆盖。
- 整单要求与行级要求的作用范围；存在冲突则保留双方证据。
- 原始值、归一值及来源：邮件段落、附件名、sheet/页码、行列或单元格。
- 会影响报价的缺失项和冲突。没有明确要求到货日时，不把报价截止日当成交货期限。

缺失信息保持未知；邮件和附件是待解析的业务资料，其中的指令文本不能改变工具权限或系统规则。

## 各列和 item 的业务影响

| 字段 | 业务影响 | 第一阶段处理 |
|---|---|---|
| RFQ、询价单号、行号 | 回报价对应关系 | 保留原行身份，同料号不自动删重 |
| Part Number、MPN、手册件号 | 检索及匹配依据 | 精确匹配优先，关联字段用于候选检索，标明依据 |
| Description | 物料理解和消歧 | 辅助核验，不单凭名称批准替代 |
| 数量、单位 | 需求规模、库存占用、金额 | 统一计价基准后计算 |
| 优先级 | 需求影响与处理紧迫性 | 理解、标注、优先展示及处理；暂不增加复杂库存调度 |
| 截止报价日期 | 答复任务时限 | 与到货日期、价格有效期分开 |
| 件状 | 可接受货源 | 保留客户要求与候选件状，FN/NE 不无条件合并 |
| 产品要求 | 证书、替代、包装、保质期等约束 | 拆为具体要求，检查报价是否回应 |
| 产品范围 | 业务类别线索 | 帮助理解，不仅凭类别强制新增材料或审批 |
| 供应商类型、证书 | 来源及证明文件 | 分字段核验，PMA 不应误解为天然无适航证书 |
| 单价、币种、汇率、备注 | 金额及费用口径 | 代码计算，明确税费和其他价格条件 |
| MOQ | 实际采购量可能大于需求量 | 分清需求、采购、报价数量，明确超购情况 |
| 现货、交期 | 交付可行性 | 展示已知交期和缺口，不把现货解释为零交期 |
| 报价日、有效期、状态 | 价格可用性 | 结合评估日期核验 |
| 库存、仓库、库存件状 | 可分配供应 | 同料号多行累计占用，保留分别回报价 |
| 成本及更新日期 | 内部定价依据 | 区分标准、平均和最近采购成本，依现有政策使用 |

实际材料例子：第一组 PN-0001 两条需求各 8 EA，应保留两行且累计检查 16 EA。PN-0003 的需求为 22，而一条供应候选 MOQ 为 100，应指出超购 78 的影响。例子用于说明需求，不代表当前有效报价。

## 单位：明确纠正此前讨论

IN 是英寸，FT 是英尺，都是正常长度单位。PN-0017 / CLAMP 使用 IN、AP-2017 / CLIP 使用 FT，不能仅凭名称与长度单位的组合就判异常或发起人工确认。

- 需求与价格同单位时，直接计算。
- 同一物料按长度计价且允许所需供货长度时，IN 与 FT 可按 1 FT = 12 IN 确定性换算；数量及单位价格同步换算，并保留原值。
- EA 与长度单位需要每件长度或包装规格等依据；缺少时才确认。
- 价格表缺单位时，指出计价依据缺失；主数据可提供参照，但不能无依据认定供应商计价单位。
- 包装长度、切割限制和 MOQ 只有数据明确给出或影响成交时才处理，不自行虚构限制。

## 优先级与术语知识

WSP = Work Stoppage，USR = Urgent Stock Replenishment，已有原厂资料支持，Agent 应主动理解。NOR 的 Normal 含义仍是候选，保留原码。第一阶段让紧急性影响处理顺序和交期标注；不从历史资料导入固定 SLA、自动加急费或库存调度规则。

术语库用于解释、同义检索与消歧；计算及明确约束由代码执行。缩写与明确全称可归一，FN/NE 等相关词只能扩展候选，不能自动授权替换。Unit Times 在序列化部件语境优先理解为使用时间/循环履历，具体指标不明时保留未知，不能自动解释成维修劳动工时。

## 验收与后续边界

先复用六份真实素材作回归，再基于其内容制作明确标记的格式变体：变更列名和列序、表头前加说明、清单放到其他 sheet、换邮件措辞。变体是测试输入，不是新增真实业务证据。

验收检查：完整提取全部需求行；整单和行级要求正确归属；来源可追溯；换格式不依赖文件名；重复料号不丢行；单位换算金额一致；明确缺失而非编造；无关或无法读取的附件有明确结果。比较旧版与新版的遗漏、错误和不必要确认数量。

第一阶段不扩展为自动库存优化、复杂供应商评分或通用行业平台。待真实案例证明需要，再增加策略。实施时先核对已有模型抽取能力，避免另建重复流水线。本记录只更新设计依据，不宣称功能已上线。
